# Lessons

- **No em dashes.** Not in site copy (bullets, tickers, labels) and not in replies. Use commas, colons, parentheses, or two sentences. Grep for `—` / `&mdash;` before calling copy done.
- **"Be creative" means show the work, not restyle the card.** A layout swap (flip cards → product grid) wasn't enough; the user wanted something that demonstrates what was built.
